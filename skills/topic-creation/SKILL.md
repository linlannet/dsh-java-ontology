# 主题创建技能（Topic Creation）

## 适用场景

根据研究需求创建信息监测主题，配置告警规则，启动工作流。

## 工作流程

### 第一步：主题创建
1. 根据用户描述确定主题名称、类型、热点区域
2. 调用 `topic_create` 工具创建监测主题
   - topicName: 主题名称
   - topicType: POLITICAL/ECONOMIC/SECURITY/TECH
   - hotspotRegion: 东亚/中东/欧洲/全球等
   - description: 主题详细描述

### 第二步：工作流激活
1. 使用返回的主题 ID 激活工作流
2. 工作流将自动执行七阶段：爬取→NLP→建图→分析→告警→报告→沉淀

### 第三步：告警配置
1. 根据主题类型设置告警规则
2. 配置告警级别和通知方式

## 主题类型参考

| 类型 | 说明 | 典型区域 |
|------|------|---------|
| POLITICAL | 政治动态 | 东亚、中东、欧洲 |
| ECONOMIC | 经济走势 | 全球、亚太 |
| SECURITY | 安全局势 | 中东、东欧 |
| TECH | 科技竞争 | 全球、北美 |

## 注意事项

- 主题名称应简洁明确，避免过于宽泛
- 热点区域可多选，用逗号分隔
- 创建后自动激活工作流，无需手动触发
