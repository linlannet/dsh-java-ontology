# 报告生成技能（Report Generation）

## 适用场景

根据监测数据和分析结果生成结构化报告。

## 工作流程

### 第一步：数据收集
1. 调用 `workspace_overview` 工具获取工作空间数据
2. 调用 `relation_analysis` 工具获取双边关系分析
3. 调用 `alert_query` 工具获取告警记录
4. 调用 `kg_query` 工具获取知识图谱数据

### 第二步：报告生成
1. 调用 `report_generate` 工具创建报告
   - title: 报告标题
   - reportType: WEEKLY/MONTHLY/SPECIAL/TOPIC
   - topicId: 关联主题 ID
   - content: 报告内容摘要

### 第三步：报告类型选择

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| WEEKLY | 周报 | 定期汇总本周监测数据 |
| MONTHLY | 月报 | 定期汇总本月分析成果 |
| SPECIAL | 专题报告 | 针对特定事件的深度分析 |
| TOPIC | 主题报告 | 针对特定主题的综合报告 |

## 注意事项

- 报告标题应包含时间范围和主题
- 专题报告需关联具体事件 ID
- 报告生成后自动存入工作空间，可后续查阅
